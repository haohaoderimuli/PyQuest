# 脚本交付清单（逐条打勾再交给别人）

## 入口与参数

- [ ] 有 `main(argv=None)`，模块导入时不执行业务逻辑。
- [ ] 参数来自命令行 / 环境变量，不写死在代码里。
- [ ] `--help` 列出所有参数、默认值与含义。
- [ ] 配置优先级写清：命令行 > 环境变量 > 配置文件 > 默认值。

## 运行与退出

- [ ] 成功返回 0；用法/输入错误返回 2 并给一句人话。
- [ ] 日志有级别（INFO / WARNING / ERROR），能写文件、能轮转。
- [ ] 异常只捕能处理的类型，不写 `except Exception: pass`。
- [ ] 同样参数重跑两次结果一致（覆盖写、不依赖当前时间、不追加）。
- [ ] 路径用 `pathlib`，读写显式 `encoding="utf-8"`。

## 可维护性

- [ ] 业务与流程分离：`process()` 只算，`main()` 只调度。
- [ ] 关键函数有类型注解与 docstring；数据结构用 dataclass 收口。
- [ ] 有单元测试，覆盖正常、边界、空值、异常、文件不存在。
- [ ] CI 跑 lint + 测试 + 覆盖率门禁，失败阻断合并。

## 交付物

- [ ] `requirements.txt` / `pyproject.toml` 锁版本，干净 venv 一条命令装好。
- [ ] `.gitignore` 挡住 `.venv/`、`.env`、明细数据、`__pycache__/`。
- [ ] README 有安装、最小运行命令、参数说明、出错怎么办。
- [ ] 提交历史按主题分开，提交信息写业务原因。
- [ ] 日志 / 报告 / 截图里没有 token、手机号、身份证等敏感信息。
